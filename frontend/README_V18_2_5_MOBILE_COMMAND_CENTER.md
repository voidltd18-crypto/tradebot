# V18.2.5 Mobile Command Center

Responsive-only frontend refinement for the V18.2 Command Center.

- Desktop layout preserved.
- Mobile sidebar becomes a fixed, horizontally scrollable bottom navigation dock.
- Header/status pills become compact and horizontally scrollable.
- Capital/stat cards use a compact two-column phone layout.
- Quick actions use a two-column mobile grid with Emergency Sell spanning the row.
- Command panels and detail panels stack cleanly to one column.
- Tables retain horizontal scrolling instead of crushing columns.
- Typography, card padding, chart heights, positions and system rows are tuned for narrow screens.
- PDF hidden capture host remains fixed at desktop width so mobile CSS does not distort exports.
- No backend, trading, sizing, Profit Vault, entry, exit, or AI logic changes.
